2. Compensation Letters  
Purpose  
Compensation letters formally communicate and confirm changes in an employee’s compensation, designation, and related benefits, specifying  
effective dates, payment components, and future promotion eligibility. They provide transparent, secure, and auditable documentation for  
compensation decisions across annual and adhoc scenarios.

Data Sources and Automation  
Assist platform data source overview:  
Compensation letters are generated using data from three primary sources:  
1. Excel Upload File – provides all numerical values, dates, and decision flags  
2. People Portal – provides employee designation data  
3. ASSIST System – applies templates, logic, formatting, and access control  
This separation ensures consistent letter formatting while supporting multiple compensation scenarios.  
Automated Data (ASSIST)  
The following elements are populated automatically by ASSIST and are not entered manually in the Excel file:  
Employee designation (job title)  
Retrieved from the People Portal at the time of letter generation, especially for promotion and assessment cases.  
Letter template and wording  
Standardised text, legal clauses, and closing statements are applied automatically.  
Conditional sections  
Sections related to promotion, bonuses, retention, deferred bonus, or LTI are included or excluded based on flags provided in Excel.  
Letter layout and formatting  
ASSIST ensures consistent structure, styling, and ordering of content across all letters.  
Promotion eligibility messaging  
Standard systemcontrolled wording is rendered using values supplied via Excel.  
Document generation and security  
Letters are generated as passwordprotected PDF files, with access restricted to the respective employee.  
Letter statuses  
System indicators such as “Action Required” are managed and displayed in the ASSIST UI.  
Manually Provided Data (Excel Upload)  
The Excel upload file defines what data appears in the letter and includes:  
Current and revised compensation values  
(CTC, salary components, bonuses, incentives)  
Effective dates and payout dates  
For salary changes, bonuses, deferred payments, and onetime payments  
Bonus and incentive amounts  
(OnTarget Bonus, Retention Bonus, Deferred Bonus, OneTime Bonus, LTI)  
Logical flags (Yes / No)  
Used to indicate promotion, bonus eligibility, recovery terms, and other conditional scenarios  
Promotion eligibility year  
Used by ASSIST to display the appropriate eligibility statement  
PDF password value  
Used to secure employee access to the letter  
All values must be provided as static values only; formulas are not supported.
