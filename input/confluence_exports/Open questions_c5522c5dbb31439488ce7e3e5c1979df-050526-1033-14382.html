Form 60  
1. The disclaimer can be skipped.  
2. "Are you Working From Home?" can be skipped. Not actual.  
3. Document downloading only after the employee's input is not required.  
The document is available for the employee to download as soon as the DOCS request is created. So the employee can  
download the document before and after entering their input.  
4. Status auto-changes without user action are acceptable.  
The "Employee details" form will be auto-verified the next day after the employee submits it. The form status will be  
automatically changed from "Waiting for verification" to "Verified".  
5. Possibility to request a new document not earlier than 2 (two) days after the current request is acceptable.  
The DOCS process option "Auto-closed request" works if all forms in the request are in final statuses (for example,  
"Verified", "Generated"). The minimum period for this option is 1 (one) day, but in fact the request will be closed in 2 (two)  
days.  
A new request can be created by an employee if the previous ones are closed (within a one process).  
6. The info "Actioned by: Auto Approved" for the employee can be skipped.
