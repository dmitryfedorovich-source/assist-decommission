06 — Capabilities

What the System Can Do

The workflow combines Claude Code's AI capabilities with a structured project framework, enabling a range of BA documentation tasks that would otherwise require significant manual effort.

📸

Image & Screenshot Analysis

Reads Assist platform screenshots and extracts field names, types, dropdown options, flow sequences, and UX behaviors. Results are cached in memory files and re-used in future sessions without re-reading the image.

🌐

Live Confluence Integration

Reads and searches Confluence pages in real time via MCP. Can fetch any page by ID, search within a space, and retrieve child pages. No stale exports — always reads current content from kb.epam.com.

🎙️

Meeting Transcript Processing

Extracts decisions, open questions, and action items from raw meeting transcripts. Updates the Feedback Log, phase state files, and project state automatically. Marks processed files with a prefix to prevent reprocessing.

✏️

Stakeholder Correction Application

Reads handwritten correction images, identifies what changed, applies corrections to all affected output documents simultaneously, and logs the change as a Feedback entry with source and date.

📝

Multi-Audience Document Generation

Generates different documents from the same underlying facts, with tone and content adapted per audience — management language for onepagers, structured questions for SME validation, plain instructions for employee guides.

🔍

Cross-Document Consistency Validation

Runs the validate-docs skill across all 21 output documents simultaneously, checking factual accuracy, terminology, audience fit, structural completeness, OQ cross-references, and forbidden phrases. Errors and warnings are reported with file, location, and fix.

💾

Persistent Cross-Session Memory

Stores project knowledge in structured markdown files that survive across sessions. Starting a new session loads only what's needed (tiered approach). The system "remembers" all prior decisions, open questions, and confirmed facts without re-reading source material.

📊

Decision & OQ Tracking

Maintains a living Feedback & Decisions Log with full traceability — every decision has an owner, date, source, and list of documents it is reflected in. Open questions have owners and target resolution stages. Nothing slips through.
