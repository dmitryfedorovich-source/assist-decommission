03 — Inputs

What Feeds the System

Six input types are supported. Each is processed differently and results in structured knowledge stored in the memory system.

📸

Screenshots — Assist Platform

JPEG/PNG screenshots of Assist forms, flows, and UI. A pre-read hook intercepts every image access: if a memory file already exists for that screenshot, the hook redirects to the cached file instead of re-reading the image — saving processing time.

  • Form field names and types
  • Dropdown option values
  • Workflow step sequences
  • UX behaviors (popups, warnings)
🌐

Live Confluence Pages — MCP

Direct integration with kb.epam.com via the Confluence MCP server. Pages are read in real time — no stale exports. The EPMEOADOCS space contains 7 tracked pages covering all letter types, process flows, open questions, and communication history.

  • Confirmed process decisions per letter type
  • Open questions log (India Team confirmations)
  • Communication history (7 meetings)
  • Dev trackers for each phase
🎙️

Meeting Transcripts

Auto-transcribed meeting recordings dropped into input/transcriptions/. Each transcript is processed: decisions and facts are extracted, the Feedback Log is updated, relevant phase state files are updated, and the file is renamed with a [processed]- prefix.

  • Stakeholder confirmations and rejections
  • Design decisions with owner and date
  • Open questions raised
  • Action items and next steps
✏️

Stakeholder Corrections

Handwritten correction images from document review sessions. Claude reads the image, identifies what was marked as wrong, applies the correction to the relevant output documents, and logs a Feedback entry (F-XX) in the Decisions Log.

  • Date corrections (e.g. July 1 → June 30)
  • Process step corrections
  • Terminology fixes
  • Approval flow updates
📝

Meeting Notes

Pre-meeting briefs and background notes from the BA team stored in input/meeting_notes/. Provide context for upcoming stakeholder sessions and help frame questions for India SME meetings.

📁

Confluence HTML Exports (Legacy)

Static HTML exports from early project phases, now archived. The live MCP integration replaced these as the primary source for Confluence content — exports are retained for historical reference only.
