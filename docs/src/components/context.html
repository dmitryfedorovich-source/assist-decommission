01 — Context

Why This Project Exists

assist.epam.com is being decommissioned. India employees currently use Assist to request official HR letters. Every workflow must move to docs.epam.com by June 30, 2026.

📋

The Problem

India HR document workflows live exclusively in Assist — a platform being retired. Employees need uninterrupted access to reference letters, compensation letters, and separation documents.

🎯

The Goal

Migrate all India HR letter workflows to EPAM Docs with no degradation in employee experience. Replicate existing processes, remove legacy dependencies, and go live by June 30, 2026.

🤖

The Approach

An AI-assisted BA documentation workflow — Claude Code processes inputs, maintains a persistent knowledge base, generates multi-audience docs, and validates consistency automatically.

Deadline: June 30, 2026 — Assist Reference Letters retired. All India employees must be onboarded to EPAM Docs before that date. Phase 1 (Reference Letters) is the critical path item.
