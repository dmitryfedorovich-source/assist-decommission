02 — How It Works

AI-Assisted Documentation Workflow

Raw inputs are processed through a structured knowledge pipeline. Extracted facts are stored in a tiered memory system. Claude Code uses that memory to generate, update, and validate all output documents.

Raw Materials
Screenshots · Transcripts · Confluence · Corrections
→
Knowledge Extraction
Claude Code reads & extracts decisions, facts, field specs
→
Memory System
Tiered markdown files persist knowledge across sessions
→
Document Generation
Claude writes / updates output docs per audience rules
→
Validation
validate-docs skill checks all 21 docs for consistency
→
Delivery
Stakeholder review · sign-off · dev handoff

Key principle: The Feedback & Decisions Log is the single source of truth. Every output document is derived from locked decisions in the log. When a decision changes, the validator catches which docs need updating. The AI never invents facts — it extracts, stores, and applies them.
