## 3. Message Templates

### M-01 — T-30: Employee Advance Notice

> **Subject:** Upcoming Change: HR Letter Requests Moving to a New Platform
>
> Dear colleagues,
>
> Starting **June 30, 2026**, all reference letter requests (Form 60, Address Proof, Service Letter, Visa Processing Letter, and Letter of Recommendation) will be available through **EPAM Docs (docs.epam.com)** instead of the current Assist portal.
>
> This change is part of a planned platform transition. Your letter request experience will remain the same — you will still receive the same letters, processed by the same India Team specialists.
>
> **What you need to do now:** Nothing. A full guide on using the new system will be sent to you on [June 16, 2026].
>
> **Questions?** Contact [India Team contact email].

---

### M-02 — T-14: India Colleagues Guide Distribution

> **Subject:** How to Request HR Letters from June 30 — Your Quick Guide
>
> Dear colleagues,
>
> Starting June 30, 2026, please use **EPAM Docs (docs.epam.com)** to request your HR reference letters. Assist will no longer be used for letter requests after that date.
>
> Attached is your quick guide: *[India Colleagues Guide — What's Changing and How to Use EPAM Docs]*
>
> Key points:
> - Your letter requests, fields, and processing times are the same
> - Letters available: Form 60, Address Proof, Service Letter, Visa Processing, Letter of Recommendation
> - Most letters are ready automatically; a few require specialist review (same as today)
>
> **Questions?** Contact [India Team contact email] or raise a request with [support channel].

---

### M-03 — T=0: Go-Live Announcement

> **Subject:** EPAM Docs is Now Live for HR Letter Requests
>
> Dear colleagues,
>
> Effective today, **June 30, 2026**, all reference letter requests must be made through **EPAM Docs at docs.epam.com**.
>
> Assist is no longer used for letter requests. If you try to request a letter in Assist, you will see a notice directing you to EPAM Docs.
>
> Please bookmark: [docs.epam.com link]
>
> Need help? See the guide you received earlier, or contact [India Team contact email].
