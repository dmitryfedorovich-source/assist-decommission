=======================================================
SLIDE 3 — PROCESS FLOWS
=======================================================

[Show Slide 3]

Now let me walk through the two process flows in more detail.

TRACK A — AUTO-VERIFIED (Form 60, Address Proof, Service Letter):

  The employee fills in the form and submits it. The DOCS system pulls data from the People
  system and auto-populates read-only fields. The letter is generated instantly. The employee
  downloads it.

  One thing to be aware of: the auto-verification runs as a nightly job. So briefly after
  submission, the status will show "Waiting for verification" — but this is cosmetic only.
  The employee can still download the letter. There is no actual delay or blocker.

TRACK B — MANUAL REVIEW (Visa Processing Letter, LOR):

  The employee fills in the form and submits it. The DOCS system notifies the India Team
  specialist. The specialist reviews the request and has two options:

  VERIFY: The specialist verifies the form, then manually triggers "Send Document". The
  employee receives a notification and can download the letter. The document is hidden from
  the employee the entire time — they cannot see or download it until the specialist sends it.

  REJECT: The specialist rejects the form and must provide a comment — a rejection reason is
  mandatory. The employee is notified, opens the same rejected form, makes corrections, and
  resubmits it. The specialist is then notified to re-verify. There is no limit on how many
  times this can happen.

AUTO-CLOSE BEHAVIOR:

  Once a request is complete — meaning the letter has been generated for Track A, or the
  specialist has sent the document for Track B — the request auto-closes after 2 days if the
  India Team specialist has not manually closed it first. This keeps the queue clean
  automatically.

  Important: a rejected form does not count as completed. The request stays open for the
  employee to resubmit.

SLIDE 6 — COMMON BEHAVIORS
=======================================================

[Show Slide 6]

This slide covers behaviors that apply consistently across all 5 letter types. Let me go
through each one briefly.

1. SELF-DECLARATION CHECKBOX
   In Assist, a popup appeared before submission. In DOCS, there is a Self-Declaration section
   at the bottom of each request form with a full disclaimer text and an "Accept" checkbox.
   The employee must tick the checkbox before they can click Submit. This applies to all 5
   letter types.

2. REJECTION — EDIT AND RESUBMIT SAME FORM
   When a specialist rejects, they must leave a comment — this is mandatory. The employee is
   notified, edits the same form (not a new request), and resubmits. No limit on resubmissions.

3. AUTO-CLOSE AFTER 2 DAYS
   Once all forms in a request reach final status, the request auto-closes after 2 days if the
   specialist hasn't closed it manually.

4. ONE ACTIVE REQUEST AT A TIME
   An employee cannot submit a new request for the same letter type while a previous one is
   still open. They must wait for the previous request to close — which happens within 2 days
   via auto-close.

5. NOTIFICATIONS
   Employees receive notifications when their letter is ready for download, and when their
   form is rejected (with the rejection reason).
   Specialists receive a notification as soon as the employee submits all required forms —
   telling them a request is waiting for verification.

6. DATA PRE-POPULATION FROM PEOPLE SYSTEM
   Date is auto-generated by DOCS. Name, Designation, UID, Work Location, Birth Location,
   Start Date, and Address (for Address Proof Letter) are all pulled from the People system
   and are read-only. If an address is incorrect, the employee must update their People
   profile first.

7. COMMENTS FIELD
   The Comments field on Visa Processing Letter supports max 300 characters, single line.
   The Roles & Responsibilities field on LOR supports up to approximately 6000 characters,
   multi-line.

8. RM APPROVAL REMOVED
   The RM approval step that existed in Assist is not used in DOCS. For Track B letters,
   the India Team specialist (DV/EDV role) verifies and sends the document directly.
   No RM involvement.

9. AUTO-VERIFICATION STATUS CHANGE (Track A)
   For Form 60, Address Proof, and Service Letter — the form is auto-verified the next day
   after submission. The status changes from "Waiting for verification" to "Verified"
   automatically. No action needed from employee or specialist.

10. PURPOSE FIELD — "CUSTOM" TEXT INPUT
    The Purpose dropdown on Address Proof Letter, Service Letter, and LOR includes a "Custom"
    option with a free-text field. This text field is always visible on the form, optional,
    max 100 characters, single line.

11. ADDRESS PROOF — ADDRESS LOCKED
    As mentioned earlier, the address on Address Proof Letter is read-only. If incorrect,
    update via People system.
