Process Flows

All 5 letters follow one of two tracks. RM approval is removed from all letters in DOCS (confirmed decision D-12, D-13, D-15).

Track A — Auto-Verified Form 60 · Address Proof Letter · Service Letter
Employee Fills form & submits
→
DOCS System Auto-verifies data from HR systems
→
DOCS System Letter generated instantly
→
Employee Downloads letter
Auto-verification runs as a nightly job. Status shows "In Verification" briefly — this is cosmetic and does not block the employee from downloading.
Track B — Manual Review Required Visa Processing Letter · LOR
Employee Fills form & submits
→
DOCS System Notifies India Team specialist (DV/EDV)
→
India Team Reviews request
→
Approve →
India Team "Send Document" action
→
Employee Notified & downloads letter
Reject →
India Team Rejects with reason
→
Employee Opens NEW request
Document is hidden from the employee until the India Team specialist manually triggers "Send Document". The employee sees no download button before that action.

Common Behaviors

These behaviors apply consistently across all 5 letter types. Please confirm each is acceptable.

📋
No Confirmation Popup (Disclaimer Text Instead)
In Assist, a popup with a checkbox appeared before submission. DOCS does not support this popup. A static disclaimer text will appear at the top of each form — employees read it and submit directly, without clicking a checkbox.
🔄
Rejection → New Request (No Resubmit)
When an India Team specialist rejects a request, the employee is notified with the rejection reason. The employee must open a new request — there is no resubmit option on the rejected request.
⏱️
Auto-Close After 2 Days
Once a request reaches final status (letter generated or sent), it auto-closes after 2 days if the India Team specialist has not manually closed it. This is configurable — please confirm the interval is correct.
🔒
One Active Request at a Time
An employee cannot submit a new request for the same letter type while a previous request is still open. A new request can only be created after the previous one is closed (takes up to 2 days via auto-close).
🔔
Notifications
Employees receive system notifications for: request submitted (review-required letters), letter ready for download, request rejected (with reason). India Team specialist receives a notification for each new request pending review.
⚙️
Data Pre-Population from HR Systems
Name, Designation, UID, Work Location, Birth Location, Start Date are pulled automatically from HR systems. Employees cannot edit these fields. Address for Address Proof Letter comes from the People platform (edit behavior: OQ-14).
⚠
Please confirm (Q6.1–Q6.4): Are these behaviors acceptable?
Specifically: (a) static text disclaimer instead of checkbox popup, (b) new-request-only on rejection, (c) 2-day auto-close interval, (d) one active request at a time cooldown.

OQ-14 Address Proof Letter
Address Proof Letter: should employees be able to edit the pre-filled address directly in the DOCS form, or should the field be locked so employees must update their address in the People system first?
Option A (Allow edit): Employee can correct address directly in the form before submitting. Faster for the employee, but the People profile stays outdated.

Option B (Lock field): Address field is read-only. Employee must go to People Portal to update, then return. Ensures People profile stays accurate.

Out of Scope — Confirm Boundaries

Please confirm that these items are correctly excluded from Phase 1. Check each box to indicate your agreement.

Item Our Understanding Confirmed

Cancel request by employee Nice-to-have — NOT in Phase 1 MVP. Employees cannot cancel a request once submitted. They must wait for it to close (auto-close: 2 days after final status).

RM initiating requests on behalf of employees Reporting Managers do not have direct access to create DOCS requests for other employees. If an RM needs to initiate, they route via ServiceNow → India Team specialist who acts on behalf of the employee.
