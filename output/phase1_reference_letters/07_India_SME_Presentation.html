Process Flows

All 5 letters follow one of two tracks. RM approval is removed from Track A (auto-verified) letters. Track B routing (Visa Processing Letter, LOR) is under review — RM approval mechanism pending agreement (OQ-15).

Track A — Auto-Verified Form 60 · Address Proof Letter · Service Letter
Employee Fills form & submits
→
DOCS System Reuse data from People system
→
DOCS System Letter generated instantly
→
Employee Downloads letter
Auto-verification runs as a nightly job. Status shows "Waiting for verification" briefly — this is cosmetic and does not block the employee from downloading.
Track B — Manual Review Required Visa Processing Letter · LOR
Employee Fills form & submits
→
DOCS System Notifies India Team specialist (DV/EDV)
→
India Team Reviews request
→
Verify →
India Team "Send Document" action
→
Employee Notified & downloads letter
Reject →
India Team Rejects with reason
→
Employee Edits & resubmits same form
Document is hidden from the employee until the India Team specialist manually triggers "Send Document". The employee sees no download button before that action. When verifying, no comment is required. When rejecting, a comment is required — the specialist cannot reject without providing a reason (D-19).
ⓘ
Auto-Close Behavior: Once a request reaches final status (letter generated for Track A, or "Send Document" triggered for Track B), it auto-closes after 2 days if the EPAM specialist has not manually closed it. Note: a rejected form (document within a request) is not in final status — the request stays open for the employee to edit and resubmit the form. The 2-day interval is configurable — SME confirmation required.

Common Behaviors

These behaviors apply consistently across all 5 letter types.

📋
Self-Declaration Checkbox at Bottom of Form (D-21)
In Assist, a popup with a checkbox appeared before submission. DOCS implements a Self-Declaration section at the bottom of each request form with a full disclaimer text and an "Accept" checkbox that the employee must tick before clicking Submit.
🔄
Rejection → Edit & Resubmit Same Form
When an EPAM specialist rejects a form/document, they must provide a required comment. The employee is notified, opens the same rejected form, makes corrections, and resubmits. The system notifies the specialist to re-verify. No limit on resubmissions.
⏱️
Auto-Close After 2 Days
Once all forms within a request reach a final status (Verified / Generated), it auto-closes after 2 days if the India Team specialist has not manually closed it.
🔒
One Active Request at a Time
An employee cannot submit a new request for the same letter type while a previous request is still open. A new request can only be created after the previous one is closed (takes up to 2 days via auto-close).
🔔
Notifications
Employee receives: letter ready for download; request form rejected (with reason).
EPAM specialist receives: request waiting for verification — triggered as soon as the employee submits all required forms in the request.
⚙️
Data Pre-Population from People System
Date is auto-generated by DOCS. Name, Designation, UID, Work Location, Birth Location, Start Date, and Address (Address Proof Letter) are pre-filled from the People system — all read-only. If the address is incorrect, the employee updates their People system profile (D-20).
💬
"Comments" Field — Required Visa Processing Letter  ·  LOR (active employees)
The "Comments" field in the request is required and supports text input with character and formatting constraints. Constraints vary by letter type:
Visa Processing Letter: max 300 characters, single line, no paragraphs.
LOR for active employee (Roles & Responsibilities field): max ~6000 characters, multiple lines, paragraphs supported.
✅
RM Approval — Under Review for Track B (OQ-15) Visa Processing Letter  ·  LOR (active employees)
OQ-15 (open): Satish Malla confirmed at the India SME validation meeting (14 May 2026) that RM approval is a mandatory step in the current Assist process for both letter types. The DOCS platform does not currently support RM routing. A solution must be agreed before Track B development can begin — see Track B Solution Options document (08). The DV/EDV verification step itself is confirmed: after the RM approval question is resolved, the specialist verifies and shares the document via the "Send Document" option.
🔁
Auto-Verification Status Change Form 60  ·  Address Proof Letter  ·  Service Letter
The "Employee details" form is auto-verified the next day after the employee submits it. The form status changes automatically from "Waiting for verification" to "Verified" — no action required from the employee or specialist.
📝
Purpose Field — "Custom" Text Input Address Proof Letter  ·  Service Letter  ·  LOR (active employees)
Dropdown values for all three letters have been provided. The "Custom" option in the Purpose dropdown includes a free-text input field that is optional (not required) and always visible in the form — present regardless of which Purpose value is selected. Constraints: max 100 characters, single line of text, no paragraphs.
🏠
Address Proof Letter — Address Field Read-Only (D-20) Address Proof Letter
The employee's address is pre-filled from the People system and locked (read-only) on the Address Proof Letter form. Employees cannot edit the address directly on the form. If the address is incorrect or missing, the form shows a note directing the employee to update their People system profile first.
